# Hi, I'm Lucas

I build open-source tools for AI agents, from model integrations and engineering workflows to desktop applications.

## Selected projects

- **[Y Harness](https://github.com/tobenwarrior/y-harness)** — An extensible agent harness built on DeepSeek Harness, with a desktop app and multiple model providers.
- **[Compound Skills](https://github.com/tobenwarrior/compound-skills)** — Engineering workflows and interactive code maps for Codex, Cursor, and Claude Code.
- **[Kiro ACP](https://github.com/tobenwarrior/hermes-kiro-provider)** — Connects Kiro CLI to Hermes Agent as a model provider through ACP.
- **[Provider Copy](https://github.com/tobenwarrior/hermes-provider-copy)** — Copies provider API keys between Hermes bot profiles on request, without transferring OAuth credentials or messaging bot tokens.
- **[need-follow-up](https://github.com/tobenwarrior/need-follow-up)** — Telegram notifications when Claude Code needs approval or completes a task.
